# Privacy Notice

Compose Config Inspector does not collect, transmit, sell, or share personal data, project files,
configuration values, usage statistics, or telemetry.

Inspection runs locally. When the user starts an inspection, the plugin invokes the locally installed
Docker Compose command-line tool and reads its local output. No dedicated backend service is used.

information under their own privacy terms. Docker Compose is governed by its provider's terms.
